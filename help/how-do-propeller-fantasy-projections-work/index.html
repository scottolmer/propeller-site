How do Propeller fantasy projections work?

Last updated: 2026-10-14

By Scott Olmer, Founder; designated author and editorial owner. Produced and reviewed through automated AI workflows. Editorial policy.

Direct answer: The first row answers the question selected by the sort. Point projection orders central estimates; Floor orders lower scenarios; Ceiling orders upper scenarios. None is a guarantee or a complete starting-lineup decision. Read the other two numbers, keep the scoring system and slate consistent, and check the source’s status before using the order.

Evidence: Fantasy projection methodology Public board and sort control Documented fantasy facts Historical response and provenance

What goes into a fantasy projection?

Propeller converts available current hitter-stat market components into DraftKings MLB fantasy points. For scoring components without current market coverage, it uses recent form. Each eligible hitter receives a central point estimate and lower and upper scenarios. The public feature covers MLB hitters; it does not publish pitcher projections or fantasy projections for other sports.

The point projection is the central estimate. The floor and ceiling use recent outcome variation to describe lower and upper scenarios around it. They are widened P20/P80-style estimates, not hard limits or calibrated probabilities. A player can finish below the floor or above the ceiling. The methodology page explains how those ranges are constructed.

All numbers in the examples below use DraftKings MLB fantasy-point units and one decimal place. Compare rows on that same scoring basis and slate. A similar-looking number from a different scoring system answers a different question.

Point projection asks: which central estimate is highest? The order is A 10.0 → B 9.0 → C 8.0. A leads on that question, while B still has a higher floor and C a higher ceiling.

Floor asks: which lower scenario is highest? The order is B 6.0 → A 4.0 → C 3.0. That makes B first in this sort. It does not promise that B will score at least 6.0 points.

Ceiling asks: which upper scenario is highest? The order is C 20.0 → A 16.0 → B 12.0. C moves from last by central estimate to first by upper scenario. That is a change of question, not evidence that C’s projection improved.

The current public board’s sort handler reorders the loaded values by the selected field. Changing that control does not recalculate those three values. This describes the public MLB board, not every signed-in interface. Do not average the three ranks into an invented overall recommendation.

What should I check before using the order?

First, name the question: central estimate, lower scenario or upper scenario. Then read the selected player’s other two numbers. Keeping the full row in view prevents a single high value from standing in for everything you need to know.

Next, confirm the scoring label, slate and source status. The public board shows the source update time and labels usable data “live data” or “latest available data.” A stale source flag, missing update time or age over 60 minutes triggers the latter. If the preview cannot load usable rows, it says unavailable and keeps teaching examples labelled. A fresh page visit does not by itself establish fresh inputs.

Finally, check what the table cannot settle. Player availability and role still matter. Salary, roster constraints and contest rules can affect a lineup decision, but this feature does not import salaries, optimize lineups, manage exposure or submit entries. Propeller is independent of DraftKings and the other platforms it references.

A useful research note is simple: “I sorted by floor, compared all three values on the same slate and scoring system, and checked the source status.” Add any unresolved information before deciding what to research next. The first row is a place to inspect, not an instruction to start a player.

Frequently Asked Questions

How do Propeller fantasy projections work?

Propeller combines available current hitter-stat market components with recent form for uncovered scoring events, converts them to DraftKings MLB fantasy points, and supplies a central estimate with lower and upper scenarios.

Which players and sports are covered?

The public fantasy projection feature covers MLB hitters only. Pitchers and other sports are not part of the public launch.

Is the highest floor guaranteed?

No. Floor is a lower scenario, not a minimum result. Actual points can fall below it, just as they can exceed the ceiling.

Does sorting recalculate the projections?

The public MLB board’s sort control reorders the loaded rows by point projection, floor or ceiling. It does not recalculate the three values in that sort handler.

Is the first row a lineup recommendation?

No. It is the highest value for the selected sort within the displayed rows. Read all three values and check scoring, slate, freshness and information the table cannot settle before making your own decision.
