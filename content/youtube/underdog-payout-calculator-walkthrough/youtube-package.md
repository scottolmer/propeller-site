## Description

Underdog payout math starts with one formula: entry amount × the multiplier shown for that entry. This walkthrough shows how to estimate Standard and Flex payout scenarios without treating a possible payout as a prediction or guarantee.

Free Underdog payout calculator: https://propellerpicks.com/tools/underdog-payout-calculator/

You’ll learn how to:

- read total payout versus payout minus entry;
- build an illustrative 5-pick Standard scenario;
- read 6-pick Flex result rows;
- use the hit-rate field as your own what-if assumption, not a Propeller forecast;
- check Classic versus Champions availability; and
- verify the current amount on Underdog’s final entry screen.
