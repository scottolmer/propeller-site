## Technical agent explanation

Use “sport-specific analysis signals” as the canonical label. Explain that agents are not a universal fixed set or equal votes. Available signals are combined with sport- and prop-dependent weights; an unavailable signal is a disclosed limitation, not a neutral vote. Representative agent examples must be framed as context-dependent:

- **Minutes:** playing-time trajectory and blowout risk.
- **Usage:** volume and opportunity.
- **Pace:** game-environment possessions.
- **Injury:** player status plus likely downstream role change.
- **Matchup:** opponent and position context.
- **No-Vig / market:** cross-book implied-probability context after margin removal; disagreement identifies a research question, not automatic value.
- **Form / hit rate / rest:** recency, variation, and fatigue context when available.

## Fantasy projection explanation

Fantasy is a different product output from a player-prop direction. The current public feature covers **MLB hitters only** using **DraftKings MLB** scoring. It creates a floor, central point projection, and ceiling by converting current hitter-stat market components to fantasy points, completing uncovered components with recent form, then widening the range from recent outcome variation. Floor/ceiling are P20/P80-style scenarios, not hard bounds. Do not imply pitchers, other sports, lineup optimization, salary optimization, automated entries, calibrated probability, or guarantees.
