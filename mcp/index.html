Direct answer

What is the Propeller MCP server?

MCP (Model Context Protocol) is a standard way for AI assistants to use outside tools. Propeller's server gives your assistant read access to your Propeller research: stored props, Confidence Scores, game logs, injury reports and saved picks.

It is included with full workspace access, including existing free accounts. Your AI tool's own plan and usage limits still apply.

  1. 01Add the serverPaste the server URL into your AI tool's connector or MCP settings.
  2. 02Sign in to PropellerYour tool opens a Propeller sign-in page. Review the permissions and approve.
  3. 03Ask a questionYour assistant calls Propeller when a question needs prop, player or pick data.

Install

Add Propeller to your AI tool.

It is a remote server with sign-in, so there is nothing to download. Menu names change between app versions. If a label differs, look for "connectors", "integrations" or "MCP servers".

Claude Web, desktop and mobile
  1. Open Settings → Connectors.
  2. Choose Add custom connector.
  3. Name it Propeller and paste https://mcp.propellerpicks.com/mcp as the URL.
  4. Select Connect, sign in to Propeller and approve access.
  5. In a new chat, turn the Propeller connector on from the tools menu if it is not already on.

Connectors you add on the web also show up in Claude Desktop and the Claude mobile apps. On Team and Enterprise plans an owner may need to add the connector first.

Claude Code Terminal

Run this once:

claude mcp add --transport http propeller https://mcp.propellerpicks.com/mcp

Then start Claude Code, type /mcp, pick propeller and choose Authenticate to sign in. Add --scope user to make Propeller available in every project.

ChatGPT Web
  1. Open Settings → Apps & Connectors → Advanced settings and turn on Developer mode.
  2. Back in Apps & Connectors, choose Create.
  3. Name it Propeller, paste the server URL and choose OAuth for authentication.
  4. Save, sign in to Propeller and approve access.
  5. In a chat, add Propeller from the + menu under Developer mode.

Custom MCP connectors in ChatGPT depend on your ChatGPT plan and workspace settings.

Cursor Editor

Add Propeller to ~/.cursor/mcp.json (all projects) or .cursor/mcp.json (one project):

{
  "mcpServers": {
    "propeller": {
      "url": "https://mcp.propellerpicks.com/mcp"
    }
  }
}

Open Cursor Settings → MCP and select Login next to propeller to sign in.

VS Code GitHub Copilot agent mode

Add Propeller to .vscode/mcp.json, or run MCP: Add Server from the Command Palette and choose HTTP:

{
  "servers": {
    "propeller": {
      "type": "http",
      "url": "https://mcp.propellerpicks.com/mcp"
    }
  }
}

Select Start above the server entry, then follow the sign-in prompt.

Other MCP clients

Any client that supports remote MCP servers with OAuth sign-in should work:

  1. URL: https://mcp.propellerpicks.com/mcp
  2. Transport: Streamable HTTP
  3. Authentication: OAuth. You sign in with your Propeller account; there is no API key to paste.

Available tools

What your assistant can look up.

Your AI tool picks the right tool on its own. You do not need to name them.

read_nba_data

NBA players, teams, schedule, results, game-log statistics, props, picks and the ranked top-picks board.

read_mlb_data

The same capabilities for MLB.

read_nhl_data

The same capabilities for NHL.

read_soccer_data

The same capabilities for soccer.

read_nfl_data

The same capabilities for NFL.

search_nfl_players

Finds an NFL player by name, with typo tolerance. If more than one player matches, your assistant should ask which one you mean.

get_top_nfl_props

Upcoming NFL props ranked by Confidence Score. Filter by player, game or platform, or return one prop per player.

get_nfl_player_context

A player's recent stored game logs and latest stored injury report.

get_nfl_parlay_candidates

One 2–6 leg NFL research combination for a platform you name, with different players and games, an adjusted confidence and risk flags. No payout or joint probability.

review_saved_pick

Reviews a line and side you saved in Propeller against timestamped evidence.

Sport coverage varies by season, slate and available data. The NFL tools accept PrizePicks, Underdog, DraftKings Pick6, Sleeper and Betr, plus sportsbook lines as market context.

Things to ask

  • "Why does Propeller lean Less on this NBA points line?"
  • "Review the pick I saved yesterday. Has anything changed?"

Use safely

What it does not do.

  • Bets and entries

    The server only reads research. It cannot place bets or submit DFS or pick'em entries, and Propeller does not accept wagers.

  • Line freshness

    Answers come from Propeller's recorded analyses and captured lines. Check the line on your platform before you decide.

  • Confidence Scores

    The 50–100 Confidence Score is a directional research signal, not a win probability or a guarantee.

  • Payouts and combined odds

    Combination tools do not calculate payouts or the chance that every leg hits.

  • Your AI tool's limits

    Your assistant's plan, message limits and accuracy are set by that tool. It can still misread a result, so check anything important in the Propeller app.

Questions

Before you connect.

What is the Propeller MCP server?+

It is a remote Model Context Protocol server at https://mcp.propellerpicks.com/mcp. After you sign in, a compatible AI tool can read your Propeller research: stored player props, Confidence Scores, game logs, injury reports and saved picks.

Does the Propeller MCP server cost extra?+

No. MCP access is included with full workspace access, including existing free accounts that keep their access free. Your AI tool's own plan and usage limits still apply. See pricing for current access details.

Can my AI tool place bets or submit entries through Propeller?+

No. The server is read-only research. Propeller does not accept wagers, place wagers or submit DFS and pick'em entries, and neither does the MCP server.

How do I disconnect an AI tool from Propeller?+

Revoke the connection from Propeller assistant connections. You can also remove the server inside your AI tool's settings.
